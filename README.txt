MAINSTITCHES WEBSITE - FREE HOSTING

1. Create a free GitHub account.
2. Create a PUBLIC repository named YOURUSERNAME.github.io (replace YOURUSERNAME with your GitHub username).
3. Upload index.html and the entire images folder to the root of that repository.
4. In Settings > Pages, choose Deploy from a branch, main, /(root), Save.
5. Visit https://YOURUSERNAME.github.io after deployment.
6. Once you confirm the site works, update GoDaddy domain forwarding to your new GitHub Pages URL, or configure custom-domain DNS per GitHub Pages instructions.

IMPORTANT: Your current mainstitches.com forwarding goes to Amazon. Do not change it until the new website is live.
